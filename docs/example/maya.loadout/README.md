# Maya's loadout

Work the way they work.

Mined from 42 Claude Code sessions over 30 days. 4 rules, 4 playbooks, 3 ways of asking, 5 skills.

Playbooks:

- **Build a feature**: Building or adding a feature
- **Fix a bug**: Fixing a bug, an error or a failing test
- **New idea or plan**: Starting from a new idea, a plan or a concept
- **Review**: Reviewing code or a pull request

## Use it

In Claude Code, with the loadout plugin installed:

```
/loadout:use maya
```

Or from a terminal: `loadout use ./maya.loadout`. `/loadout:off` turns it off.
